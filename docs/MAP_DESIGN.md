# Map Design — Highland Vale

## Goals

A compact but readable three-lane MOBA layout for the prototype, expandable later.

## Layout

- Southwest base: Highland Covenant (**Clanheart**)
- Northeast base: Iron Crown (**Royal Bastion**)
- Diagonal mid lane: **King's March**
- Northern arc: **Highland Road**
- Southern arc: **Mistwood Path**
- Central marsh tint between the roads
- Jungle pockets for Moor Hounds and Ancient Stag
- Rocks / ruin obstacles as hard collision

## Prototype scope

- Full spatial three-lane readability
- Functional combat primarily on middle lane waves
- One tower per lane per side
- Camera bounds clamped to map extents

## Future

- Outer / inner tower tiers
- Barracks unlocking super minions
- River objective / boss pit for the Wyrm
- denser forest pathing graphs
