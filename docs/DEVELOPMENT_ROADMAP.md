# Development Roadmap

## Phase 1 – Foundation (current)

- Repository and tooling
- Engine / scene structure
- Test map, camera, movement
- First hero, minions, towers
- Basic combat and HUD

## Phase 2 – Core MOBA

- Full three-lane wave combat
- Richer jungle and objectives
- Gold / XP / items polish
- Ability VFX pass
- Stronger bots
- Clear victory / defeat flow

## Phase 3 – Art Integration

- Meshy heroes, minions, monsters, buildings
- Environment kit
- Animation binding
- Comic rendering pass
- Effects and audio

## Phase 4 – Content

- Multiple heroes and roles
- Item trees
- Map boss: The Wyrm Beneath the Moor
- Faction story surfaces
- Balancing tools

## Phase 5 – Multiplayer

- Authoritative server
- Lobby / matchmaking
- Sync, reconnect, stats, load tests
